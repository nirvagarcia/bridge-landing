## 🧠 ¿Qué es Bridge?

**Bridge** es una aplicación peruana impulsada por **inteligencia artificial** que traduce la **Lengua de Señas Peruana (LSP)** a **texto y voz en tiempo real**, con el objetivo de reducir la brecha comunicativa entre personas oyentes y la comunidad sorda.  
Su landing page está desarrollada con **Next.js 15**, **React 19** y **Material UI**, priorizando la **accesibilidad**, el **rendimiento** y la **inclusión digital**.

> 🌍 Proyecto desarrollado por **Nirvana García** y **Michelle Moreno**, desde Lima, Perú 🇵🇪.
